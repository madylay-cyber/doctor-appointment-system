git init — инициализация нового локального репозитория в папке проекта. Создает скрытую директорию .git для отслеживания изменений.
git remote add origin <url> — связывание локального репозитория с удаленным репозиторием на сервере GitHub.
git branch -M main — принудительное переименование текущей главной ветки по умолчанию в main для соответствия современным стандартам.
git config --global user.name "Имя" — глобальная идентификация разработчика в системе. Связывает имя автора с каждым будущим коммитом в репозитории.
git config --global user.email "Ваш_Email" — указание контактного почтового адреса автора изменений (необходимо для синхронизации аккаунта с профилем на GitHub).
git status — проверка текущего состояния рабочего каталога (показывает измененные, новые и неотслеживаемые файлы).
git add . — добавление всех измененных и новых файлов проекта (включая служебные файлы .gitignore, документацию TZ.md и код) в индекс (Staging Area) для последующего сохранения.
git add <имя_файла> — точечное добавление конкретного файла в индекс.
git commit -m "сообщение" — фиксация (сохранение) снимка состояния проекта в локальной истории с осмысленным описанием выполненного этапа разработки.
git checkout -b develop — создание новой ветки разработки develop и автоматическое переключение на неё.
git checkout main — переключение обратно на главную стабильную ветку проекта.
git branch -a -v — вывод списка всех существующих веток (как локальных, так и удаленных на GitHub) с отображением последнего коммита в каждой из них.
git push -u origin develop — первая отправка ветки develop на GitHub с установкой связи между локальной и удаленной ветками.
git push — отправка последующих локальных коммитов в текущую активную ветку на сервере GitHub.
Pull Request (через веб-интерфейс GitHub) — запрос на проверку кода и слияние (merge) изменений из ветки разработки develop в основную ветку main.
git log --oneline --graph --all — визуализация всей истории коммитов в виде компактного текстового графа, отражающего хронологию разработки, хэши коммитов и точки разветвления/слияния веток.
