##  5. Известные ограничения и непроверенные сценарии
1. **Непроверенные сценарии:** Нагрузочное тестирование (Stress & Load Testing) и проверка устойчивости API под экстремальным потоком параллельных запросов (>5000 RPS).
2. **Обоснование:** Данные проверки сознательно исключены из границ (Out-of-Scope) Лабораторных работ №9–10 согласно ТЗ. Приложение спроектировано для локальной автоматизации работы регистратуры районной клиники, где пиковые нагрузки перекрываются возможностями встроенного механизма блокировок SQLite.
3. **Техническое ограничение:** Использование СУБД SQLite ограничивает параллельную запись конкурирующих потоков (блокировка на уровне файла БД), что нивелируется быстрой скоростью транзакций.
