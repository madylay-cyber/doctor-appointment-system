# 🚀 Инструкция по запуску пакета автоматических тестов (ЛР №10)

Пакет содержит 10 регрессионных и интеграционных автотестов, проверяющих бизнес-логику ИС, регулярные выражения схем Pydantic и аппаратную защиту от двойного бронирования.

### 🛠 1. Подготовка окружения
Перед запуском убедитесь, что в вашем виртуальном окружении установлены утилита `pytest` и ASGI-клиент:
```bash
pip install pytest httpx
```

### ⚡ 2. Локальный запуск тестов
Для прогона всех 10 тестов с выводом детальных логов по каждому сценарию выполните команду в корне проекта:
```bash
python -m pytest testing/lab10/ -v
```
*Все тесты используют фикстуру隔離 (изоляции), разворачивая чистую структуру таблиц в оперативной памяти `:memory:`. Тесты полностью безопасны и не изменяют боевой файл СУБД `medical.db`.*
