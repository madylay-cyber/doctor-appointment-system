# Спецификация HTTP-кодов ответов API МИС
- **200 OK**: Успешная авторизация, выгрузка реестра приемов и карточки ЭМК.
- **201 Created**: Успешное бронирование нового слота времени к врачу.
- **400 Bad Request**: Нарушение бизнес-логики (запись на прошедшее время).
- **403 Forbidden**: Нарушение ФЗ-152 при попытке неавторизованного доступа к ЭМК.
- **404 Not Found**: Полис ОМС или ID приема не найдены в СУБД.
- **409 Conflict**: Аппаратная блокировка Race Condition при дублировании времени слота.
- **422 Unprocessable Entity**: Ошибка формата ввода (валидация регулярных выражений Pydantic).
